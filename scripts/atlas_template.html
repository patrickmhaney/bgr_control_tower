Reproducing this

The diagrams on this page are generated from the Mermaid source committed in docs/data_model.md and docs/ingestion.md, so the page cannot drift from the repository. The pipeline lineage was extracted from the dbt manifest after a full build.

pip install -r requirements.txt once, in a virtual environment python run_ingestion.py --explain the extraction spec, per table python run_ingestion.py source systems → landing → raw dbt build 80 models, 207 tests python scripts/verify_ingestion.py prove ingestion changed nothing python scripts/build_atlas.py rebuild this page

Source data is a seeded mock standing in for the real systems, modelled to reproduce their behaviour rather than their contents — CHAR padding, sentinel dates, string-typed exports, missing change tracking. Two source systems, Netstock and Pangea, remain unidentified and carry real schedule risk. Three of the seven defined metrics cannot be computed from any source that exists today.
